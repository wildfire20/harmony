B. Remember Me checkbox must react immediately

Current production behavior:

user taps “Keep me signed in on this device”
checkbox appears unchanged
only after pressing Sign In does it visually turn green

This is incorrect.

The checkbox must be driven by local React state immediately.

Expected interaction:

Tap checkbox
→ checked state changes immediately
→ visible tick/checkmark appears immediately
→ selected state changes immediately
→ pressing it again immediately clears it

Do not wait for form submission or server response.

Verify the input is properly controlled, for example through the appropriate checked state and onChange/accessible label handling.

The entire checkbox + label area should be tappable.

Preserve keyboard accessibility and focus state.

C. Persistent login still fails in REAL production

Previous work fixed:

remember → rememberMe

But real production testing after deployment still fails:

parent checks Keep me signed in
parent logs in successfully
parent closes the browser completely
browser is removed from recent apps
parent later reopens Harmony Parent Portal
login screen appears again

Browser/password autofill does not count as authentication.

Therefore do not assume the previous fix solved the issue.

Trace the actual production session lifecycle end-to-end.

Verify:

Checkbox state really produces rememberMe: true.
Network login request reaching the backend actually contains the correct boolean.
Backend creates the remembered 30-day session family.
Login response actually emits the refresh Set-Cookie.
Browser accepts and stores that cookie.
Cookie contains the intended production attributes:
HttpOnly
Secure
SameSite=Lax
correct Path
actual persistent Max-Age/Expires
Cookie remains present after browser closure.
On a fresh page load, frontend startup authentication runs before deciding the user is logged out.
Startup refresh request actually includes credentials/cookies.
Refresh endpoint receives the cookie.
Refresh endpoint validates the session family.
Access token/auth state is restored.
Parent Portal is rendered without showing the login form.
Selected learner is restored after authentication.

Do not rely only on unit tests.

Find the first point in that chain that fails.
