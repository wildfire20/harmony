1. Fix “Mark received”

However, when Admin clicks:

Mark received

the operation fails and a red error notification appears.

Check:

Admin authentication/authorization
backend review endpoint
expected review-state value
checklist state transition
database constraints
current production migration/schema compatibility
transaction/locking logic
whether UPLOADED_PENDING_REVIEW → RECEIVED is mapped correctly

The intended behavior is:

Uploaded / Pending review
→ Admin clicks Mark received
→ document becomes Received
→ checklist becomes Received
→ review timestamp/Admin reviewer is recorded
→ audit event is created
→ UI updates immediately

The parent/application must not lose any data if the review action fails.
