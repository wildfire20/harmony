# Harmony Finance Integrity Phase
## Multi-Fee Allocation + Service Charges + Discounts + One-Off Reconciliation + Proof Preview + Submission Reliability

We need to complete and harden the Harmony Learning Institute finance workflow.

Several connected production issues have now been identified.

This is NOT just a UI patch.

Audit the current finance architecture first and then fix the underlying generic issues so Admin, Parent Portal, Excel exports, invoices, one-off fees and payment history all use the same authoritative financial truth.

DO NOT:
- deploy automatically
- run migrations automatically
- directly overwrite immutable historical payment transactions
- hardcode fixes for Milton/HAR049
- hardcode sibling/staff discount amounts
- infer discounts from legacy sibling/staff-child checkboxes
- reconstruct historical finances by guessing
- create a second independent finance ledger

Preserve the existing authoritative finance ledger, immutable reversal/correction architecture, audit trail and Parent security.
