==================================================

Preferred format:

HLI-2027-0001
HLI-2027-0002
etc.

Requirements:

- Never overwrite a valid existing application_reference.
- Only assign references where application_reference IS NULL or empty.
- Backfill in a stable order such as application ID / created_at.
- Ensure every assigned reference is unique.
- Preserve existing application IDs.
- Do not renumber any record that already has a valid reference.

After backfill, align the sequence so the next new application receives a number greater than every existing assigned reference.

Example:

Existing references:
HLI-2027-0001
HLI-2027-0002
HLI-2027-0003

Next generated application:

Do not risk duplicate sequence values.
