Commit approval and token issuance first.
Send the approval email afterward.

The approval email must contain:

Complete Registration

linking securely to:

/registration/:token

Also provide the plain-text link.

UNDER_REVIEW
NOT_ACCEPTED

4. Admin secure-link controls

Add controlled Admin actions:

Resend Email
Reissue Secure Link
Revoke Secure Link

Rules:

Resend Email

Reuse the existing active token.
Do not silently create another token.

Reissue Secure Link

Explicit Admin action only.
Revoke the current token.
Generate a new token.
Send the appropriate email after commit.

Revoke Secure Link

Revoke access immediately.
Do not change the admissions status.

Never display:

token hashes
raw token database values
internal IDs
