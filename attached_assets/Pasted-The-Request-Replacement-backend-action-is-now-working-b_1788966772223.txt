Add a parent replacement-notification workflow.

When Admin clicks Request replacement:

Require or allow a short parent-safe replacement reason.
Commit the document/checklist state as REPLACEMENT_REQUIRED.
After commit, automatically send the parent an email through the existing Gmail API transport.

learner name
application reference
document that needs replacement
parent-safe replacement reason
Add a prominent Replace Document button.
Reuse the existing active secure Update Application link if it is still valid and eligible.
Do not automatically reissue a token merely because a replacement was requested.
If the existing secure link is expired/revoked/unavailable, explicitly issue a new secure link before sending the email.
Include the plain-text secure URL as well.
Preserve the existing in-person option where appropriate.

On the parent secure portal:

Clearly highlight the affected document as:
Replacement required
Display the parent-safe reason from Harmony.
Show Upload replacement
If physical submission is allowed, also show Bring replacement in person

create a new document version
preserve the old file in protected review history
