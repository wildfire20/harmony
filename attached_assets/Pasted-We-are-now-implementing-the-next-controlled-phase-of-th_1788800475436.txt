5. APPLICATION RECEIVED CONFIRMATION
==================================================

When a new application is successfully submitted:

FIRST:
save the application successfully.

ONLY AFTER successful persistence:
send the confirmation.

Do not claim the learner has been accepted.

Parent email:

Subject:
Harmony Learning Institute — Application Received

Suggested wording:

Thank you for applying to Harmony Learning Institute for the 2027 academic year.

We have successfully received your application.

Application Reference:
[REFERENCE]

Our admissions team will review the application and contact you regarding the next steps.

Please keep your application reference for future communication.

Harmony Learning Institute

Use the parent/guardian email supplied in the application.

Do NOT send:
- passwords
- private student portal credentials
- sensitive documents
- banking credentials
- internal notes

If email sending fails, DO NOT delete or roll back the successfully submitted application.

Log the email failure safely for Admin follow-up.

7. STATUS CHANGE EMAILS
==================================================

When Admin intentionally changes an application status, send an appropriate parent email.

Do NOT send an email when:
- an application is merely opened/viewed
- internal notes change
- the same status is saved again

UNDER REVIEW:

Subject:
Harmony Application Update — [REFERENCE]

Message:
Your application is currently being reviewed by our admissions team.

MORE INFORMATION REQUIRED:

Subject:
Additional Information Required — [REFERENCE]

Message:
Harmony requires additional information before the application can proceed.

If the Admin system already supports a safe message/note field intended for parents, allow Admin to include a short explanation.

Do not send private/internal Admin notes.

APPROVED:

Subject:
Application Approved — Harmony Learning Institute

Message:

We are pleased to inform you that the application referenced [REFERENCE] has been approved.

The next step is to complete the registration process.

Further registration instructions will be provided through the secure Harmony registration process.

IMPORTANT:
Approval must ONLY be triggered by an Admin changing the status to APPROVED.

Submitting an application must NEVER automatically approve it.

REGISTERED:

Subject:
Welcome to Harmony Learning Institute — [REFERENCE]

Use a simple welcome message.

Do not invent:
- start dates
- teacher assignments
- class placement
- transport route
- boarding room
unless those details exist and have been verified in the system.

NOT ACCEPTED:

Use respectful neutral language.

Do not include internal reasons unless Admin explicitly provides parent-safe text.

8. PREPARE APPROVED → REGISTRATION FLOW
==================================================

Do NOT build a huge registration system blindly.

First inspect the current admissions/enrollment database and application form.

Prepare the architecture for:

Approved application
       ↓
Secure registration link
       ↓
Parent completes additional registration details
       ↓
Required documents uploaded later
       ↓
Admin reviews registration
       ↓
Registered

For this task:

- create the safest foundation for a secure registration link if practical
- do NOT expose registration by predictable application ID
- use a cryptographically secure token
- token must be tied to one application
- do not expose another applicant's information
- define a reasonable expiration/reissue mechanism

If this requires substantial schema work, STOP after designing the schema and report the recommended implementation rather than introducing risky changes.

The registration workflow itself can be completed in the next phase.
